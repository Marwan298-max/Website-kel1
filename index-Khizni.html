Tentang Project Info
Latar Belakang

Satu hub, lima game, nol dependensi.

Project ini adalah kumpulan game yang dikerjakan secara mandiri oleh masing-masing anggota Kelompok 1. Semua game dikumpulkan ke dalam satu halaman hub biar gampang diakses — cukup buka, pilih, dan mainkan.

Nggak ada server, nggak ada instalasi. Semua berjalan langsung dari file HTML di browser, jadi bisa dibuka di mana aja dan kapan aja.

  • Semua game berjalan langsung di browser, tanpa install apa pun.
  • Ditulis murni dengan HTML, CSS, dan JavaScript.
  • Setiap anggota mengerjakan gamenya sendiri dari nol.
  • Ringan dan responsif — nyaman dibuka di HP maupun laptop.
Cara Memainkan 03 Langkah
01

Pilih Game

Scroll ke bagian Karya Anggota, terus pilih game yang mau dimainkan. Tiap kartu ada nama pembuatnya.

02

Klik Mainkan

Tekan tombol "Mainkan Game". Halaman game bakal kebuka di tab baru, jadi hub-nya tetap terbuka di sini.

03

Langsung Main

Nggak perlu daftar atau download apa-apa. Game-nya jalan langsung — kalau ada kendala, kabarin pembuatnya ya.
